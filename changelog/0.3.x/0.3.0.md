# 0.3.0 — 2026-08-30

## Changed

- **`imf://database/{dataflow_id}`** now returns bounded codelist previews with `unfiltered_count`, `matched_count`, `returned_count`, `offset`, `next_offset`, and a `continuation` object naming `imf_get_database`; callers that relied on complete inline codelists must continue with `dimension_id`, `limit`, and `offset` instead. ([#40](https://github.com/cyanheads/imf-mcp-server/issues/40), [#43](https://github.com/cyanheads/imf-mcp-server/issues/43))
- **`imf_get_database`** pages one selected `dimension_id` after the optional `codelist_filter`, reports `truncated` across `structuredContent` and `content[]`, and keeps every unselected preview capped at 50 entries. ([#36](https://github.com/cyanheads/imf-mcp-server/issues/36), [#40](https://github.com/cyanheads/imf-mcp-server/issues/40))
- **2026-07-28 metadata responses** now emit one-hour public cache hints on `tools/list`, `prompts/list`, `resources/list`, `resources/templates/list`, `resources/read`, and `server/discover`; `imf_list_databases` and `imf_get_database` also declare `openWorldHint: true`. ([#37](https://github.com/cyanheads/imf-mcp-server/issues/37), [#44](https://github.com/cyanheads/imf-mcp-server/issues/44))

## Fixed

- **`codelist_filter`** trims once at the schema boundary, rejects whitespace-only values, and preserves the recovery split between a filter miss and an unresolved codelist. ([#36](https://github.com/cyanheads/imf-mcp-server/issues/36), [#40](https://github.com/cyanheads/imf-mcp-server/issues/40))
- **`dataflow_list_unavailable`** now stays visible through the bounded resource and `imf_get_database` instead of being relabeled as a generic structure failure. ([#43](https://github.com/cyanheads/imf-mcp-server/issues/43))

## Dependencies

- `@biomejs/biome` `^2.5.10` → `^2.5.11` (dev)
- `@types/node` `^26.2.0` → `^26.4.0` (dev)
