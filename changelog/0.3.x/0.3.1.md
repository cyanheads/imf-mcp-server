# 0.3.1 — 2026-08-30

## Changed

- **`imf_query_dataset`** accepts `output_mode: "canvas"` to stage any result, while `staged` now distinguishes DataCanvas placement from preview `truncated` state. ([#39](https://github.com/cyanheads/imf-mcp-server/issues/39))
- **Staged results** preserve full series metadata and a describe-before-query retrieval workflow in both MCP result channels. ([#41](https://github.com/cyanheads/imf-mcp-server/issues/41))

## Fixed

- **Daily period bounds** reject calendar-invalid dates before upstream calls. ([#35](https://github.com/cyanheads/imf-mcp-server/issues/35))
- **Upstream data errors** retain their original MCP code, reason, recovery hint, and cause. ([#45](https://github.com/cyanheads/imf-mcp-server/issues/45))
- **Automatic DataCanvas placement** measures the complete MCP response and limits only the observation preview; unrepresentable fixed metadata returns `response_too_large`. ([#48](https://github.com/cyanheads/imf-mcp-server/issues/48))
