# 0.2.4 — 2026-07-11

## Fixed

- **`imf_query_dataset` period validation**: malformed `start_period`/`end_period` values and reversed ranges (`start_period` after `end_period`) are now rejected as `ValidationError` (reasons `invalid_period_format`, `invalid_period_range`) before the upstream IMF call. Previously a malformed period was silently treated as unfiltered and a reversed range surfaced a misleading `no_data` error. ([#11](https://github.com/cyanheads/imf-mcp-server/issues/11))
- **`docs/design.md` error-code drift**: `key_dimension_mismatch` and `invalid_sql` were documented as `InvalidParams`; both throw `ValidationError` in source — corrected to match. ([#14](https://github.com/cyanheads/imf-mcp-server/issues/14))
