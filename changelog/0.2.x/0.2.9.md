# 0.2.9 — 2026-08-06

## Fixed

- **`imf_query_dataset` no longer reports `null` unit/scale/decimals on structures that don't use the IMF's own attribute spelling**: `findSeriesAttrIndex()` now matches a precedence-ordered alias list per attribute (`unit`: `UNIT`, `UNIT_MEASURE`; `scale`: `SCALE`, `UNIT_MULT`; `decimals`: `DECIMALS_DISPLAYED`, `DECIMALS`, `DECIMAL_DISPLAYED`) instead of one fixed id. `NA_MAIN` (ESTAT) now reports scale and decimals instead of nulls, and `SDG` (IAEG-SDGs) now reports unit. ([#32](https://github.com/cyanheads/imf-mcp-server/issues/32))
