# 0.2.12 — 2026-08-25

Framework maintenance. No tool, resource, or argument was added, removed, or renamed; what moved is the wire the five tools and the `imf://database/{dataflow_id}` resource are served over.

## Added

- **The `imf://database/{dataflow_id}` resource declares an `output` schema** — the dataflow metadata payload is validated against the declared shape before it reaches the client.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`.**

## Changed

- **MCP SDK v2**: `@modelcontextprotocol/sdk` is replaced by `@modelcontextprotocol/server`, and every HTTP endpoint now serves protocol revision `2026-07-28` alongside the 2025 revisions. A 2025-era client keeps negotiating what it always did.
- **Tool arguments are strict**: a key none of the five tools declares is rejected by name instead of being silently stripped, and each `inputSchema` advertises `additionalProperties: false`.
- **The advertised `outputSchema` declares the error envelope**: success fields become optional and `error` is declared, so a client that validates `structuredContent` without first checking `isError` stops rejecting an error result with `-32602`.
- **Advertised JSON Schema is 2020-12**, not draft-07.
- **`ctx.log` output reaches the client** as `notifications/message`, gated by the client's `logging/setLevel`.
- **`resources/subscribe` and `resources/unsubscribe` resolve** for `imf://database/{dataflow_id}`.
- **`MCP_SESSION_MODE` is set explicitly to `stateless` in `.env.example`**, matching what the Docker image already runs, and documented in the README config table alongside the new `MCP_HTTP_RESUMABILITY*` retention knobs for a stateful self-hosted deployment.
- **The production Docker stage omits optional peers** (`--omit=peer` on the OTEL install), so the image no longer carries the framework's opt-in service tiers. Both stages pin Bun `1.4.0`, and the build stage pins `$BUILDPLATFORM`.
- **`tsconfig.json` splits typecheck from emit** — it covers `src/` and `tests/` with `noEmit`, and `tsconfig.build.json` carries the `src`-rooted emit, so `tests/` is typechecked for the first time.
- Security contact moves to `security@caseyjhand.com`; `scripts/`, `skills/`, and `changelog/template.md` resync with the framework, including the `scripts/tree.ts` fix that drops gitignored directories from `docs/tree.md`.

## Fixed

- **`IMF_REQUEST_TIMEOUT_MS` bounds the whole exchange, not just the response headers** — a portal that answers promptly and then stalls the body now aborts with a `Timeout` instead of holding the call open.
- **An over-budget upstream error body is captured from both ends**, so an IMF diagnostic sitting behind a boilerplate preamble is no longer truncated away.
- **A tool input-validation failure reads as a flat `path: message` sentence**, not a serialized `ZodIssue[]` blob behind an `MCP error -32602:` prefix.
- **An unknown or disabled tool rejects with `-32602`** instead of resolving an `isError` result.
- **A POST with a non-JSON `Content-Type` answers `415`**, not a `-32700` parse error.
- **Request context no longer rides a service error out to the client** — `ErrorHandler` spread the handler context into `McpError.data`, which a tool returns as `structuredContent.error.data`.
