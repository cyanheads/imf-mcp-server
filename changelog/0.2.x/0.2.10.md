# 0.2.10 — 2026-08-06

## Fixed

- **`imf_query_dataset` no longer reports `null` unit on dataflows that attach `UNIT` to a subset of the series key**: SDMX 3.0 buckets such attributes as `dimensionGroup`, keyed by a partial dimension key in `dataSets[0].dimensionGroupAttributes` rather than on each series' own row. The decoder now indexes that bucket by the slots each attribute's `attributeRelationship.dimensions` names and falls back to it when the series-level row has nothing; the series row still wins if both describe a concept. 59 of 164 dataflows that declare a dimension-group unit populate it, `WEO` and the regional REOs among them — `USA.NGDP_RPCH.A` now reports `unit: "PT"` instead of `null`. `scale` and `decimals` are unaffected — neither is declared this way on any sampled dataflow. ([#33](https://github.com/cyanheads/imf-mcp-server/issues/33))

## Changed

- **`series_attributes.unit` / `series_metadata[].unit` are documented as upstream codes** (`PT`, `USD`, `XDC`, `NUM`) rather than resolved names — dimension-group unit codelists carry no `name` field, unlike the series-attached case; tool descriptions and the README updated to match.
