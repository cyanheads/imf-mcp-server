# 0.2.6 — 2026-08-06

## Added

- **`imf_get_database` `codelist_filter` echo**: the output now echoes the applied `codelist_filter` (absent when none was set), and a new `enrichment.notice` fires when a filter matches nothing in any dimension (naming the filter and unfiltered entry counts) or when a dimension's codelist could not be resolved at all — the two previously rendered as the same empty array with no way to tell them apart. ([#27](https://github.com/cyanheads/imf-mcp-server/issues/27))

## Changed

- **Dimension `name` now a real label**: `imf_get_database` and the `imf://database/{dataflow_id}` resource resolve `dimensions[].name` from the DSD's concept scheme (e.g. `WGT_TYPE` → `Weight Type`) instead of echoing the dimension id back as its own name; falls back to the id when the structure names no concept. ([#28](https://github.com/cyanheads/imf-mcp-server/issues/28))
- **`imf_get_database` description reconciled with the 50-entry cap**: tool description, output field descriptions, README, and `docs/design.md` now describe a capped codelist *preview* per dimension rather than a "complete" codelist — the resource remains the uncapped source. ([#19](https://github.com/cyanheads/imf-mcp-server/issues/19))

## Fixed

- **Codelist resolution on IMF-authored dataflows**: `normalizeDsd()`'s naming-convention fallback was the only resolution path, and it missed on 7 of 30 sampled dataflows (`NA_MAIN`, `SDG`, `QNEA`, `LS`, `CTOT`, `DIP`, `IMTS`) — worst case 9 of 14 dimensions on `NA_MAIN`. Codelists are now resolved from the dimension's own `localRepresentation.enumeration` URN, then the referenced concept's `coreRepresentation.enumeration` URN (the only machine-readable reference IMF-authored DSDs carry), before falling back to the naming convention; lookup widens from `AGENCY:ID:VERSION` to `AGENCY:ID` to `ID` since a URN's cited version routinely trails the shipped codelist's patch. `SdmxStructureResponse.localRepresentation.enumeration` is retyped from an object to the URN string IMF SDMX 3.0 actually sends. ([#20](https://github.com/cyanheads/imf-mcp-server/issues/20))
