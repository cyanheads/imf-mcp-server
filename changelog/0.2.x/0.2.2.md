# 0.2.2 — 2026-06-20

## Added

- **`scripts/check-dependency-specifiers.ts`** — new devcheck step (`Dependency Specifiers`) that hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json`'s dependency sections and `bun.lock`'s `workspaces` map. Catches a `bun update --latest` writing a literal `latest` dist-tag into the lock. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **`devcheck.config.json` `packaging.pluginManifests`** (default on) — enables `lint:packaging` check 10, which validates `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` for non-empty descriptions, the unscoped machine name on display fields, and the full scoped name on the `npx -y` install arg. ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.6` → `^0.10.9`. Brings the `DuckdbProvider.describe({ tableName })` binder-error fix (filtered `describe()` raised an ambiguous-column Binder Error on every canvas table-list query), the `ctx.content` collector for image/audio blocks, and a sharper canvas SQL gate that classifies `SELECT`-shaped prepare failures as `invalid_sql` with the DuckDB binder detail instead of `non_select_statement`. Re-synced 14 agent skills and the framework devcheck scripts. ([cyanheads/mcp-ts-core#235](https://github.com/cyanheads/mcp-ts-core/issues/235), [#236](https://github.com/cyanheads/mcp-ts-core/issues/236), [#239](https://github.com/cyanheads/mcp-ts-core/issues/239))
