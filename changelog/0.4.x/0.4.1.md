# 0.4.1 — 2026-08-31

## Added

- **`imf_get_database`** accepts `available_only=true` to page codes with published data, including per-dimension counts and series/time coverage ([#47](https://github.com/cyanheads/imf-mcp-server/issues/47)).

## Changed

- **`imf_list_databases.filter`** trims input, rejects blank filters, and matches dataflow IDs, names, and full descriptions ([#46](https://github.com/cyanheads/imf-mcp-server/issues/46)).
- **Availability discovery** caches uncapped dataflow coverage for one hour while preserving the bounded query-recovery diagnostic.
