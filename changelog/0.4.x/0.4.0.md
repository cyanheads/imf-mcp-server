# 0.4.0 — 2026-08-30

## Added

- **`imf_dataframe_drop`** removes one staged DataCanvas table or view when `IMF_ENABLE_DATAFRAME_DROP=true`; repeated or absent drops report `dropped: false` without affecting other tables ([#42](https://github.com/cyanheads/imf-mcp-server/issues/42)).

## Changed

- **`imf_dataframe_query`** retains the largest row prefix whose complete structured and formatted response fits 100,000 characters, with deterministic pagination guidance and a `response_too_large` recovery when one row cannot fit ([#38](https://github.com/cyanheads/imf-mcp-server/issues/38)).
- **DataCanvas configuration and install metadata** expose the opt-in cleanup flag across stdio, HTTP, MCPB, and server documentation.
